# HealthcareTelephoneType

The kind of telephone number (work, home, mobile, fax or other)

## Example Usage

```java
import to.unified.unified_java_sdk.models.shared.HealthcareTelephoneType;

HealthcareTelephoneType value = HealthcareTelephoneType.WORK;

// Open enum: use .of() to create instances from custom string values
HealthcareTelephoneType custom = HealthcareTelephoneType.of("custom_value");
```


## Values

| Name     | Value    |
| -------- | -------- |
| `WORK`   | WORK     |
| `HOME`   | HOME     |
| `MOBILE` | MOBILE   |
| `FAX`    | FAX      |
| `OTHER`  | OTHER    |
